# Shop App

SPA приложение для просмотра каталога продуктов.

## Стек

- React + TypeScript
- Redux Toolkit + RTK Query
- React Router
- React Hook Form + Zod
- CSS Modules
- Vite

## Функциональность

- Каталог продуктов с пагинацией
- Лайки и удаление карточек
- Фильтрация по избранному
- Страница продукта с подробной информацией
- Создание нового продукта через форму с валидацией

## Примечание

Из-за того, что API позволяет осуществять только чтение, есть некоторые ограничения:

Созданные пользователем продукты хранятся в Redux store (in-memory) и не сохраняются после перезагрузки страницы, так как API (fakestoreapi.com) не поддерживает реальное создание данных.

Редактировать можно только продукты, созданные пользователем.

## Установка

```bash
npm install
npm run dev
```
